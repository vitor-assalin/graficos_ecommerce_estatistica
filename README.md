# Análise de Dados de E-commerce

Este projeto foi realizado como atividade de análise de dados utilizando a base de dados de e-commerce.

Foram criados gráficos para analisar os dados e visualizar melhor as informações presentes na base, utilizando Python e bibliotecas como Pandas, Matplotlib e Seaborn.

Os gráficos realizados foram:

- Histograma
- Gráfico de dispersão
- Mapa de calor
- Gráfico de barras
- Gráfico de pizza
- Gráfico de densidade
- Gráfico de regressão
